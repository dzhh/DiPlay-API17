# 验证范围

唯一实车环境详见 README。实车结果来自车主逐次测试反馈，不是跨设备认证。

| 功能 | 验证情况 |
| --- | --- |
| 有线画面、触摸、媒体、导航、Siri 回复 | 目标车/手机组合已有成功反馈；Siri 于 0.32 后确认恢复 |
| USB 重连、倒车影像、音频路由 | 车主反馈改善并可用，不代表所有异常路径已覆盖 |
| 15 fps | 车主反馈比此前高帧率方案流畅 |
| 0.33 清屏、精简 UI、启动阶段显示 | 本地与 API17 模拟器检查；等待后续实车验证 |
| 方向盘各键/来电蓝牙共存 | 不宣称全量实车验证通过；来电原车电话界面仍可能弹出 |
| 自动确认系统授权 | 未证明可在该车权限条件下可靠实现 |
| 无线/其他车辆/其他手机 | 未验证 |

源码包含协议、边界、状态机及媒体策略单元测试。API17 模拟器不等于 i.MX6 真机，不能验证厂商音频路由、真实麦克风、USB 时序或真实流畅度。
