# DiPlay API17 — 比亚迪宋 DM 有线 CarPlay 实验移植

基于 [shihabal3amri/DiPlay](https://github.com/shihabal3amri/DiPlay) 的 Android 4.2.2 / ARMv7 有线 CarPlay 移植，针对一台老款比亚迪车机做兼容性调整。当前推荐使用 **0.34 有线稳定版**。2026-10-11 已停止无线及后续双向音频实验，私人在线通道仅提供 0.34 稳定功能。主分支保留历史 0.36 调查源码，稳定源码见 [stable/wired-0.34](https://github.com/hange3514/DiPlay-API17/tree/stable/wired-0.34)。

**只在下述一套真实车辆和手机组合上测试过，没有在其他车型、车机、手机或 iOS 版本上测试过。不代表通用兼容，也不保证安装后即可连接。** 本仓库不是 Apple 或比亚迪官方产品，没有宣称 MFi/CarPlay 认证。

## 已做的主要更改

- 将连接服务、界面与依赖适配到 API 17；使用独立 Java/Kotlin 客户端、兼容密码实现及 ARMv7 JNI 库。
- USB 发现、启动监听与后台连接；处理 USB 重新枚举、通道关闭、超时取消及会话资源回收，减少必须重启车机才能重连的问题。
- 调整车机前后台和 Surface 生命周期，使倒车/避障影像可以覆盖投屏；停止、拔线或断连后用黑色遮罩清除可见的最后一帧。
- 优化 H.264 输入、缓冲和呈现路径，使用该车实测更稳定的 15 fps；不是声称达到原生 CarPlay 的流畅度。
- 适配车机媒体/导航音频路由、焦点、播放增益、录音与播报冲突；针对已识别固件增加 Siri 回复期间暂停物理录音、维持静音上行的兼容方案。
- 加入方向盘事件接入代码，包括上一曲、下一曲、接听和挂断；音量保留原车处理。代码具备不等于所有按键组合均已实车验证。
- 保留在线更新、日志提交及环境检测的客户端实现；更新校验包名、版本、摘要和安装签名。公开源码不连接维护者私人服务，需自行配置后端。
- 精简连接界面，移除方向盘检测入口、帧率调试提示及自动确认适配提示；替换启动图标。
- 分拆启动阶段与耗时记录，区分身份认证、手机端就绪、网络握手和首帧等待，避免把所有等待误认为认证耗时。

详细验证范围和限制见 [docs/TESTING.md](docs/TESTING.md)，版本摘要见 [CHANGELOG.md](CHANGELOG.md)。

## 当前维护状态：只保留 0.34 有线版

**0.34 已由车主确认有线使用正常，冻结基线保持不变。** 不再继续无线或第三方实时语音双向音频实验。无线在这台 MX9A0 的现有硬件、原厂固件和已获得接口条件下未能实现，本项目不提供无线支持；尚无充分证据断言硬件在所有方案下绝对不可能实现。详见 [无线调查结论](docs/WIRELESS_FEASIBILITY.md)。

私人在线通道现仅提供 `0.34.0-stable-r40`：原始 0.34 程序、资源与认证资产保持不变，仅调整安装编号并重新签名，以允许覆盖安装现有 0.40 实验版。停止连接后可点「回退到0.34有线稳定版」，或在「在线更新」中核对版本后选择「重新安装本版」。原始 0.34 用户无需升级；通道不会再提供后续实验版。

回退与安装仍需系统确认。历史机制见 [稳定基线与回退机制](docs/STABLE_ROLLBACK.md)。公共 GitHub 仍只提供脱敏源码，不分发私人 APK。

## 插入手机后的授权窗口

以下说明针对上面的唯一实测车机，操作均在停车时进行。这两个窗口都显示在车机上：

| 弹窗 | 应如何操作 |
| --- | --- |
| 「允许应用“图库”访问该 USB 设备吗？」 | 点 **取消**，不要勾选「默认情况下用于该 USB 设备」。不要把 iPhone 的 USB 连接交给图库。 |
| 「DiPlay有线移植 尝试创建 VPN 连接」 | 先勾选 **我信任此应用**，再点 **确定**，允许本应用建立连接所需的 VPN 通道。 |

**简记：图库取消，DiPlay 的 VPN 允许。** 这不是让你拒绝 DiPlay 自己的 USB 访问授权；若系统明确询问是否允许 **DiPlay** 访问 iPhone/USB 设备，应允许。不要将其他应用的 VPN 授权也一律允许。

该车机可能在每次开机后的首次连接重新弹出 VPN 授权，需要再次手动确认。目前不保证能自动处理这些系统窗口。上述图库窗口也不是 iPhone 上的 CarPlay/信任确认窗口。

## 已知限制

- 无线 CarPlay 不支持：本车现有环境下未能实现，已停止研究；这不是对所有硬件改造或其他车机的绝对不可行声明。
- 原车电话界面仍可能在来电时出现；不要将现有实现理解为所有蓝牙通话共存问题已解决。
- VPN/图库 USB 授权窗口受系统权限控制。没有证据证明无 root、无可用无障碍授权时可以可靠自动确认；不会宣称已解决。
- Siri 固件兼容路径采用半双工：回复期间不能依靠持续收音打断 Siri，需要重新唤醒。iPhone 第三方实时语音（实测豆包）不能正常双向通话，后续实验未解决，不应将有线稳定理解为支持所有应用音频场景。
- 连接速度依赖手机端 USB 状态、认证与握手；没有宣称消除了全部启动等待。
- 老旧 Android 上的系统权限、安全更新及硬件差异仍需自行评估。安装、设置和测试请停车后进行。
